/** * ============================================================ * publicarAnaliseConcluida — gatilho de "Concluído" da página Minhas Análises * ------------------------------------------------------------ * ARQUIVO NOVO E INDEPENDENTE. Não altera nenhum dos seus scripts. * Cole num arquivo .gs novo do MESMO projeto Apps Script e instale * um acionador onEdit próprio para a função publicarAnaliseConcluida * (o Sheets permite vários acionadores onEdit ao mesmo tempo). * * COMO INSTALAR O ACIONADOR (uma única vez): * Editor do Apps Script > ícone do relógio (Acionadores) > * Adicionar acionador > * Função: publicarAnaliseConcluida * Implantação: Head * Origem do evento: Da planilha * Tipo de evento: Ao editar * Salvar e autorizar. * * O QUE FAZ: * Ao marcar o checkbox da coluna I (9) na aba Dashboard: * - lê atividade, data de envio, link da análise e ID Drive da linha * - acha o ID Cademi do aluno na aba Recebimento (join pelo ID Drive) * - publica no worker cdu-analises para aparecer na página do aluno * Ao DESMARCAR o checkbox: remove a análise da página. * ============================================================ */ var ANALISES_WORKER_URL = "https://cdu-analises.mateusaugusto91.workers.dev"; var ANALISES_SENHA = "ukulele-publica-2026"; var ANALISES_ABA_DASH = "Dashboard"; var ANALISES_ABA_RECEB = "Recebimento"; var ANALISES_COL_CHECK = 9; // coluna I = checkbox "Concluído" var ANALISES_LINHA_INICIO = 3; // os dados começam na linha 3 // Colunas da aba Dashboard (1 = A) var DASH_COL_DATA = 1; // A Data de Envio var DASH_COL_ATIVIDADE = 4; // D Atividade var DASH_COL_LINK = 7; // G Link da Análise (YouTube) var DASH_COL_IDDRIVE = 19; // S ID Drive (chave do join) // Colunas da aba Recebimento (1 = A) var RECEB_COL_IDCADEMI = 8; // H ID Cademi var RECEB_COL_IDDRIVE = 23; // W ID Drive function publicarAnaliseConcluida(e) { if (!e || !e.range) return; var sh = e.range.getSheet(); if (sh.getName() !== ANALISES_ABA_DASH) return; if (e.range.getColumn() !== ANALISES_COL_CHECK) return; var linha = e.range.getRow(); if (linha < ANALISES_LINHA_INICIO) return; var marcado = e.range.getValue() === true; var dataEnvio = sh.getRange(linha, DASH_COL_DATA).getValue(); var atividade = sh.getRange(linha, DASH_COL_ATIVIDADE).getValue(); var rawLink = sh.getRange(linha, DASH_COL_LINK).getValue(); var idDrive = sh.getRange(linha, DASH_COL_IDDRIVE).getValue(); if (!idDrive) return; var idCademi = buscarIdCademiPorIdDrive_(idDrive); if (!idCademi) return; var payload = { senha: ANALISES_SENHA, idCademi: String(idCademi), rawLink: String(rawLink || ""), atividade: limparAtividadeAnalises_(atividade), dataEnvioBr: formatarDataBrAnalises_(dataEnvio), ts: dataParaTimestampAnalises_(dataEnvio), acao: marcado ? "adicionar" : "remover" }; // Marcou mas ainda não colou o link da análise: não há vídeo para mostrar. if (marcado && !payload.rawLink) return; try { UrlFetchApp.fetch(ANALISES_WORKER_URL + "/publicar", { method: "post", contentType: "application/json", payload: JSON.stringify(payload), muteHttpExceptions: true }); } catch (err) { // Silencioso de propósito: nunca trava o seu fluxo normal da planilha. } } // Acha o ID Cademi na aba Recebimento, casando pelo ID Drive. function buscarIdCademiPorIdDrive_(idDrive) { var ss = SpreadsheetApp.getActiveSpreadsheet(); var receb = ss.getSheetByName(ANALISES_ABA_RECEB); if (!receb || receb.getLastRow() < 2) return ""; var n = receb.getLastRow() - 1; var ids = receb.getRange(2, RECEB_COL_IDDRIVE, n, 1).getValues(); var alvo = String(idDrive).trim(); for (var i = 0; i < n; i++) { if (String(ids[i][0]).trim() === alvo) { return receb.getRange(i + 2, RECEB_COL_IDCADEMI).getValue(); } } return ""; } function limparAtividadeAnalises_(at) { if (!at) return ""; return String(at).replace(/^Atividade\s*\|\s*/i, "").trim(); } function formatarDataBrAnalises_(v) { var d = (v instanceof Date) ? v : parseDataAnalises_(v); if (!d) return String(v || ""); return Utilities.formatDate(d, "America/Sao_Paulo", "dd/MM/yyyy"); } function dataParaTimestampAnalises_(v) { var d = (v instanceof Date) ? v : parseDataAnalises_(v); return d ? d.getTime() : 0; } function parseDataAnalises_(txt) { if (!txt) return null; var s = String(txt).trim(); var m = s.match(/(\d{2})\/(\d{2})\/(\d{4})(?:\s+(\d{2}):(\d{2}))?/); if (!m) return null; return new Date(+m[3], +m[2] - 1, +m[1], m[4] ? +m[4] : 0, m[5] ? +m[5] : 0); }
